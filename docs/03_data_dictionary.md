# Data Dictionary

## 1. Purpose

This document describes the data structures used in the Smart Credit Analytics Platform, including dimensions, fact tables, business definitions, data types and data quality rules.

## 2. Naming Conventions

- `dim_`: descriptive dimension tables.
- `fact_`: measurable business event tables.
- `_key`: surrogate key generated inside the Data Warehouse.
- `_id`: business identifier from the source system.
- Boolean fields represent true/false business conditions.

## 3. Dimension Tables

| Field | Data Type | Key | Description | Business Rule |
|---|---|---|---|---|
| customer_key | BIGSERIAL | PK | Surrogate key generated by the Data Warehouse. | Auto-generated. |

| age | INT | - | Customer age at the time of application. | Must be greater than or equal to 18. |
| gender | VARCHAR(20) | - | Customer gender. | Optional; should not be used alone for automated decisioning. |
| education | VARCHAR(50) | - | Customer education level. | Controlled domain. |
| employment_type | VARCHAR(50) | - | Customer employment type. | Controlled domain. |
| months_employed | INT | - | Number of months in current employment. | Must be greater than or equal to 0. |
| monthly_income | DECIMAL(12,2) | - | Declared or estimated monthly income. | Must be greater than 0. |
| marital_status | VARCHAR(30) | - | Customer marital status. | Controlled domain. |
| dependents | INT | - | Number of financial dependents. | Must be greater than or equal to 0. |
| housing_status | VARCHAR(50) | - | Customer housing situation. | Controlled domain. |
| bank_relationship_months | INT | - | Number of months of banking relationship. | Must be greater than or equal to 0. |
| credit_history_months | INT | - | Number of months of available credit history. | Must be greater than or equal to 0. |

| debt_to_income | DECIMAL(6,3) | - | Debt-to-income ratio after estimated installment. | Expected range between 0 and 2.5. |

## 4. Fact Tables

### 4.1 fact_credit_applications

| Field | Data Type | Key | Description | Business Rule |
|---|---|---|---|---|
| application_key | BIGSERIAL | PK | Surrogate key generated by the Data Warehouse. | Auto-generated. |
| application_id | VARCHAR(30) | UK | Application identifier from the source system. | Must be unique and not null. |
| customer_key | BIGINT | FK | Foreign key to dim_customer. | Must exist in dim_customer. |
| location_key | BIGINT | FK | Foreign key to dim_location. | Must exist in dim_location. |
| channel_key | BIGINT | FK | Foreign key to dim_acquisition_channel. | Must exist in dim_acquisition_channel. |
| credit_profile_key | BIGINT | FK | Foreign key to dim_credit_profile_snapshot. | Must exist in dim_credit_profile_snapshot. |
| digital_risk_key | BIGINT | FK | Foreign key to dim_digital_risk_profile. | Must exist in dim_digital_risk_profile. |
| date_key | INT | FK | Foreign key to dim_date. | Must exist in dim_date. |
| application_date | DATE | - | Original application date from source data. | Must match dim_date.full_date. |
| requested_amount | DECIMAL(12,2) | - | Loan amount requested by the customer. | Must be greater than 0. |
| loan_purpose | VARCHAR(50) | - | Purpose of the loan. | Controlled domain. |
| term_months | INT | - | Loan term in months. | Must be greater than 0. |
| estimated_installment | DECIMAL(12,2) | - | Estimated monthly installment. | Must be greater than 0. |
| credit_score_internal | INT | - | Internal credit score. | Expected range between 250 and 950. |
| risk_band | CHAR(1) | - | Risk classification from A to E. | A = lowest risk; E = highest risk. |
| approved | BOOLEAN | - | Indicates whether credit was approved. | True or false. |
| approved_amount | DECIMAL(12,2) | - | Approved loan amount. | Must be less than or equal to requested_amount. |
| interest_rate_monthly | DECIMAL(6,4) | - | Monthly interest rate. | Expected range between 0 and 1. |
| default_90d | BOOLEAN | - | Indicates default within 90 days after approval. | True or false. |
| fraud_confirmed | BOOLEAN | - | Indicates confirmed fraud after review. | True or false. |
